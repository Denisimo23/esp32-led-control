# Ceiling Light — светомузыка на потолок

Потолочная адресная подсветка на **ESP32-S3 Super Mini** + **WS2812B/WS2815** + **микрофон**. Управление с телефона по **Bluetooth Low Energy** через сайт на **GitHub Pages**.

- **48 режимов**: статичные, динамические, звуковые и праздничные.
- **Полная настройка**: яркость, скорость, цвет HSV, палитра (12 готовых + своя из 3 цветов), сдвиг оттенка, чувствительность микрофона.
- **Реакция на музыку**: огибающая, бит, 8 частотных полос (Goertzel).
- **Сохранение настроек** во flash ESP32 — после перезагрузки всё восстанавливается.
- **Сайт-пульт** с VU-метром, пресетами и PWA-режимом «на экран домой».
- Работает автономно: Wi-Fi и интернет лампе не нужны, только Bluetooth.

Сайт: **https://denisimo23.github.io/esp32-led-control/**

## 2. Железо и подключение

### 2.1. Питание — самое важное

Ленту **нельзя** питать от 3.3V или 5V пина ESP32. Для 144 диодов на полной яркости нужно до **8–9 А** (около 40 Вт). Возьми внешний блок питания **5V 5–10A** (с запасом), предохранитель и конденсатор.

Обязательно:

- Общий **GND** у блока питания, ленты и ESP32.
- Электролитический конденсатор **1000 мкФ / 10 В** между +5V и GND рядом с лентой.
- Резистор **330–470 Ом** последовательно в линию данных (DIN).
- Для длинных проводов или надёжной работы — **level shifter 3.3V → 5V** (74HCT245, 74AHCT125). ESP32 выдаёт 3.3V, а WS2812B любит 5V data.
- Не подключай ленту к USB-порту платы.

### 2.2. Аналоговый микрофон (по умолчанию)

Подходит **MAX9814**, **MAX4466**, **KY-038/KY-037** (аналоговый выход).

| Модуль | ESP32-S3 Super Mini |
|---|---|
| VCC / VDD | **3.3V** (MAX9814 и MAX4466 работают от 3.3V) |
| GND | **GND** |
| OUT / AO | **GPIO 4** (ADC1) |
| GAIN (MAX9814) | оставить свободным или задать усиление |
| AR (MAX9814) | оставить свободным |

> Если модуль питается от 5V и выход у него 5V — поставь делитель или используй 3.3V-питание. Вход ESP32 не должен получать 5V.

### 2.3. Цифровой микрофон INMP441 (опционально)

| INMP441 | ESP32-S3 |
|---|---|
| VDD | 3.3V |
| GND | GND |
| L/R | GND (левый канал) |
| SCK / BCLK | GPIO 15 |
| WS / LRCLK | GPIO 16 |
| SD / DOUT | GPIO 17 |

Для него прошивай окружение `esp32s3-i2s` (см. ниже).

### 2.4. Лента

| Лента | ESP32-S3 |
|---|---|
| +5V | +5V блока питания |
| GND | GND блока питания + GND ESP32 |
| DIN | **GPIO 5** (через резистор 330–470 Ом) |

По умолчанию в прошивке:

```cpp
LED_PIN   = 5
NUM_LEDS  = 144
LED_TYPE  = WS2812B
COLOR_ORDER = GRB
MIC_PIN   = 4
MAX_MILLIAMPS = 4000
```

`GPIO 48` на многих Super Mini занят встроенным RGB-светодиодом, поэтому для ленты выбран `GPIO 5`. Если у тебя лента уже припаяна к другому пину — поменяй `LED_PIN` в `platformio.ini` или `include/config.h`.

Если лента другого типа (WS2815, SK6812, RGBW) — поменяй `LED_TYPE` и при необходимости `COLOR_ORDER` (`RGB`, `GRB`, `BGR`).

## 3. Прошивка

### 3.1. PlatformIO (рекомендуется)

1. Установи [PlatformIO](https://platformio.org/) (VS Code + расширение PlatformIO IDE или `pip install platformio`).
2. Открой папку проекта.
3. Подключи ESP32-S3 по USB.
4. Собери и залей:

```bash
pio run -t upload
```

Если PlatformIO не видит порт:

```bash
pio device list
pio run -t upload --upload-port /dev/ttyACM0
```

На Linux порт обычно `/dev/ttyACM0` (нативный USB) или `/dev/ttyUSB0` (USB-UART).

### 3.2. INMP441

```bash
pio run -e esp32s3-i2s -t upload
```

### 3.3. Если плата не прошивается

- Зажми **BOOT**, коротко нажми **RESET**, отпусти BOOT — плата войдёт в режим загрузки.
- Проверь, что кабель USB передаёт данные, а не только питание.
- Уменьши скорость: в `platformio.ini` поставь `upload_speed = 460800`.
- Если у платы 8/16 МБ flash — поменяй `board_build.flash_size` и `board_upload.flash_size` на `8MB`/`16MB`.
- Если у платы 2 МБ — поставь `board_build.partitions = min_spiffs.csv` и уменьши прошивку (BLE занимает много места).

### 3.4. Arduino IDE

Проект рассчитан на PlatformIO (несколько `.cpp` в `src/`). В Arduino IDE нужно создать скетч и положить все файлы из `src/` и `include/` в одну папку, а также установить библиотеку **FastLED**. Плата: **ESP32S3 Dev Module**, **USB CDC On Boot: Enabled**, **Flash Size: 4MB**, **Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS)**.

## 5. Как пользоваться

1. Включи блок питания лампы.
2. Открой сайт на телефоне.
3. Нажми **«Подключиться к лампе»** и выбери устройство **CeilingLight**.
4. Управляй ползунками и режимами. Все изменения сразу уходят по BLE.

### Что за что отвечает

| Элемент | Что делает |
|---|---|
| **Включить/Выключить** | общее питание подсветки (не блока питания) |
| **Режим** | один из 48 эффектов, сгруппированных по типам |
| **Случайный** | включает случайный режим |
| **Пресеты** | быстрый выбор: радуга, огонь, волна, дыхание, VU, спектр, дискотека, космос, матрица |
| **Яркость** | общая яркость 0–255 |
| **Скорость** | скорость бегущих/звуковых/праздничных эффектов 1–255 |
| **Цвет / Оттенок** | базовый оттенок HSV 0–255 (0 — красный, 85 — зелёный, 170 — синий) |
| **Насыщенность** | 0 — белый/серый, 255 — максимально насыщенный |
| **Яркость цвета** | значение V в HSV; влияет на статичный «Свой цвет» и на палитры |
| **Палитра** | 12 готовых палитр + «Своя палитра» |
| **Сдвиг оттенка палитры** | поворачивает все цвета выбранной палитры по кругу |
| **Своя палитра** | 3 цвета, между ними строится плавный градиент |
| **Режим микрофона** | выкл / огибающая / бит / спектр |
| **Чувствительность** | порог срабатывания микрофона 0–255 |
| **Синхронизировать** | перечитывает настройки из лампы |
| **Выключить** | гасит ленту и переводит режим в «Выключено» |

### Режимы микрофона

- **Выключен** — звуковые режимы показывают спокойный фон, микрофон не влияет.
- **Огибающая** — яркость/размер зависит от общей громкости.
- **Бит** — эффекты реагируют на удары (низкие частоты).
- **Спектр** — используются 8 частотных полос.

Чувствительность подбирай так: в тишине индикатор почти на нуле, на музыке — доходит до 70–100%. Если индикатор дёргается от шума — уменьши. Если не реагирует — увеличь.

### Сохранение

Настройки пишутся во flash через 1.5 секунды после последнего изменения. После выключения питания лампа вернётся к последнему режиму, цвету, палитре и чувствительности.

## 7. BLE-протокол

Сервис:

```
a1b2c3d4-e5f6-4444-8888-123456789abc
```

| Характеристика | UUID | Формат |
|---|---|---|
| mode | `...abd` | 1 байт: 0–47 |
| state | `...abe` | 1 байт: 0/1 |
| color | `...abf` | 3 байта: H, S, V |
| speed | `...ac0` | 1 байт: 1–255 |
| mic | `...ac1` | 2 байта: режим 0–3, чувствительность 0–255 |
| notify | `...ac2` | notify, 12 байт (снимок состояния) |
| brightness | `...ac3` | 1 байт: 0–255 |
| palette | `...ac4` | 11 байт |
| live | `...ac5` | notify, 4 байта |
| info | `...ac6` | строка версии |

Полные UUID имеют вид `a1b2c3d4-e5f6-4444-8888-123456789abc` (последние 3 символа меняются).

### palette (11 байт)

```
[0] paletteId 0..12
[1] hueShift 0..255
[2..4]   цвет 1 R,G,B
[5..7]   цвет 2 R,G,B
[8..10]  цвет 3 R,G,B
```

### notify (12 байт)

```
[0] версия (1)
[1] mode
[2] on
[3] brightness
[4] speed
[5] hue
[6] sat
[7] val
[8] micMode
[9] micSens
[10] paletteId
[11] hueShift
```

### live (4 байта, каждые 100 мс)

```
[0] уровень 0..255
[1] низкие
[2] средние
[3] высокие
```

Можно проверять и управлять через **nRF Connect** или любой BLE-клиент.

## 8. Если что-то не работает

### Лента не светится

- Проверь питание 5V и общий GND.
- Проверь направление ленты: данные идут от **DIN** к **DOUT**, стрелка на ленте.
- `LED_PIN` должен совпадать с реальным пином.
- `NUM_LEDS` должен быть не больше реального числа диодов.
- Первые 1–2 диода могут не работать при 3.3V data — поставь level shifter.
- Проверь, что прошивка залилась (Serial Monitor, 115200).

### Мигает, дёргается, самопроизвольно перезагружается

- Слишком слабый блок питания или тонкие провода.
- Нет конденсатора 1000 мкФ.
- Нет общего GND.
- Уменьши `MAX_MILLIAMPS` (например, до 2500) или яркость.
- Добавь резистор 330–470 Ом в data и level shifter.

### Микрофон не реагирует

- Проверь питание модуля (3.3V) и выход на GPIO4.
- В сайте выбери **Огибающая** и подними чувствительность.
- Убедись, что это аналоговый модуль. Для INMP441 прошей `esp32s3-i2s` и проверь пины SCK/WS/SD.
- В Serial Monitor должно быть `MIC: analog on GPIO4` или `MIC: I2S INMP441 ready`.

### Сайт не видит лампу

- Лампа включена и не подключена к другому телефону.
- Подойди ближе (BLE 5–10 м).
- Перезагрузи лампу.
- На Android включи Bluetooth и разрешение для Chrome.
- Сайт должен быть открыт по **HTTPS** (GitHub Pages) или `localhost`.

### Web Bluetooth недоступен

- Android: Chrome или Edge.
- iPhone: Safari не поддерживает Web Bluetooth. Используй **Bluefy**.
- На компьютере: Chrome/Edge, Linux поддерживает Web Bluetooth в Chrome.

### Не прошивается

- Зажми BOOT + RESET.
- Другой USB-кабель.
- `upload_speed = 460800`.
- Проверь размер flash в `platformio.ini`.

## 9. Настройка под себя

### Пины и лента

В `platformio.ini`:

```ini
-D LED_PIN=5
-D NUM_LEDS=144
-D MIC_PIN=4
-D MAX_MILLIAMPS=4000
```

Или в `include/config.h` (значения по умолчанию).

### Имя Bluetooth

В `include/config.h`:

```cpp
#define BLE_DEVICE_NAME "CeilingLight"
```

После смены имени поправь фильтр в `app.js` (`namePrefix: "CeilingLight"`).

### Добавить свой режим

1. В `src/effects.cpp` добавь имя в `MODE_NAMES`.
2. Увеличь `MODE_COUNT` в `include/config.h`.
3. Добавь `case` в `renderDynamic` / `renderAudio` / `renderSpecial`.
4. Добавь название в `MODES` в `app.js` и при необходимости в группы.

### Ограничение тока

`MAX_MILLIAMPS = 4000` — безопасный лимит для блока 5V/4–5A. Если у тебя 5V/10A и 144 диода, можно поставить `8000`, но тогда обязательно хорошее охлаждение и сечение проводов.

## 10. Безопасность

- 5V-лента на 144 диода — это десятки ватт. Используй предохранитель и нормальный блок питания.
- Не питай ленту от платы ESP32.
- Общий GND обязателен.
- Не оставляй блок питания без присмотра на дешёвых компонентах.
- 3.3V логика ESP32 и 5V питание ленты — не перепутай.
- Если не уверен в расчёте тока — начни с яркости 80–120 и `MAX_MILLIAMPS = 2500`.
